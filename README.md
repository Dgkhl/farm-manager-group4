# Farm Manager — Group 4
## PRG1406 Advanced Programming | BIT | May 2026

## Description
Python farm manager with inheritance, magic methods, and decorators.
The user registers animals (dairy cows or chickens), enters their data,
and the program calculates production and estimated revenue over a given period.
